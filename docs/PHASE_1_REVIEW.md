# Prototype review checklist

Open the English and Arabic routes and try these tasks without instructions from the builder:

- Find an entry-level finance vacancy, then narrow the list to a city.
- Read what is required and explain where an application would go.
- Save a vacancy, reload and find it again.
- Enter a fictional profile, compare its selected skills with a job, then clear it.
- Recover from no results and the simulated error. Open a closed vacancy.
- Repeat at 360px width using Arabic. Check long labels, zoom and keyboard focus.

Record task completion, confusion, missing information and device/network conditions. A small pilot should include early-career and experienced job seekers, including people with informal work experience.

The preview does not establish employer demand. Before phase 2, validate the proposed job categories and city coverage with real conversations, and obtain permission for source content.
